# Landing style sources

Jackal's landing components adapt the styles from these LizardByte project sites.
The shared CSS derived from the Sunshine and Koko designs is distributed under
[AGPL-3.0-only](../assets/jackal/landing/AGPL-3.0.txt).

- [Sunshine website](https://github.com/SunshineStream/SunshineStream.github.io)
- [Themerr website](https://github.com/Themerr/Themerr.github.io)
- [Koko website](https://github.com/KokoStreamTV/KokoStreamTV.github.io)

The example pages identify the original source of their content and icons.
